# Git 運用・コードレビュー・デバッグ

## Git 運用
- コンベンショナルコミット形式を使用（`feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`）
- コミットは原子的で、単一の変更に焦点を当てる
- 明確で説明的なコミットメッセージを英語で記述
- `main` / `master` ブランチへの直接コミットは避ける

## コードレビュー
- レビューコメントは建設的な改善提案として受け取る
- 個人ではなくコードに焦点を当てる
- 変更の理由と影響を明確に説明
- フィードバックを学習機会として歓迎

## デバッグ
- 問題を確実に再現できる手順を確立
- 二分探索で問題の範囲を絞り込む
- 最近の変更から調査を開始
- デバッガー、プロファイラー等の適切なツールを活用
- 調査結果と解決策を記録し、知識を共有
